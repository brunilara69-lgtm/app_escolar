Sistema Escolar

Este projeto é um aplicativo desenvolvido para facilitar o gerenciamento de informações de uma escola.

O sistema permite cadastrar e consultar informações de alunos, professores, responsáveis, matérias e boletins, reunindo os principais dados escolares em um só lugar.

🎯 Objetivo

O objetivo do projeto é criar um sistema simples para organizar os dados da escola e facilitar o acesso às informações dos estudantes e professores.

⚙️ Funcionalidades

- 👨‍🎓 Cadastro de estudantes
- 👨‍🏫 Cadastro de professores
- 👤 Cadastro de responsáveis
- 📖 Cadastro de matérias
- 📝 Cadastro e consulta de boletins
- 🔍 Consulta de informações dos alunos
- 🏫 Organização dos dados escolares

🛠️ Tecnologias utilizadas

- HTML
- CSS
- PHP
- MySQL
- XAMPP

💻 Como executar o projeto

1. Instale o XAMPP.
2. Coloque a pasta do projeto dentro da pasta "htdocs".
3. Abra o XAMPP e inicie o Apache e o MySQL.
4. Crie o banco de dados no phpMyAdmin.
5. Importe o arquivo ".sql" do projeto.
6. Acesse o sistema pelo navegador através do endereço local do projeto.
